## 变更说明

复现步骤：创建文档节点、记忆属性及其关联后导出 JSON，再导入另一个记忆库；旧导出跳过文档节点和关联，且格式没有文档元数据字段。

原因：exportMemoriesToJson 过滤 isDocumentNode，SerializableMemory 仅保存普通记忆字段，导入统一创建非文档节点。

修复：在可移植格式中加入带 serde 默认值的可选文档、访问时间和属性字段，导出包含文档节点；旧 JSON 更新时不清空原有文档元数据。
