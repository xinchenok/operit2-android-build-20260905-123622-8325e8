## 变更说明

**问题：** 首次引导成功导入聊天后，如果当前聊天 ID 为空，主聊天页仍可能创建或显示一个空会话，让迁移结果看起来丢失。

**原因：** 核心恢复聊天数据与 UI 设置当前会话是两个步骤，原完成导航没有衔接这两步。

**修复：** 导入确有聊天且当前 ID 为空时，从现有聊天摘要流中选取更新时间最近的一条，切换会话后进入应用；切换前再次检查当前 ID，保留已存在的有效选择。
