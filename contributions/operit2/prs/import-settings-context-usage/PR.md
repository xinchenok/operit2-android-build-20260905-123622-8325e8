## 变更说明

原版普通上下文模式使用最大上下文的 40%，但 Flutter 输入菜单的上下文统计始终以完整最大值作为分母。这会低估普通模式的使用率，并显示大于实际窗口的上限。

加载模型配置后，根据现有 `enableMaxContextMode` 选择最大值或 40% 的普通模式窗口，供现有 token 上限和百分比计算使用。

本次从增强补丁中只抽取原版现有能力的修复。不加入可配置的普通模式 `contextLength`；不扩展聊天角色的模型选择或统计订阅行为。
