## 问题与复现

启用一个会重放启动事件的 ToolPkg；若它的生命周期钩子访问包管理或嵌套工具，可能一直等待包管理器锁。刷新钩子的监听回调可在 `enablePackage` 持有管理器锁时同步执行。

## 原因与修复过程

原实现直接在监听回调内运行历史生命周期事件。将已收集的事件和钩子移动到已有 host task scheduler，由回调返回、管理器解锁后执行；保持事件顺序和既有钩子执行入口，调度失败使用现有 ChainLogger 报告。

## 影响与验证

影响 ToolPkg 生命周期重放，不添加旧版工具包或新的调度框架。已核对同步回调/锁关系及补丁基线；未独立编译或手机实测。复现时观察上述包可完成启用且钩子只按原事件列表执行。
