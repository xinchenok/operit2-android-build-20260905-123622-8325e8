## 变更说明

复现步骤：导入某快照后修改其中聊天，再次导入同一快照；或目标已存在相同 chat ID。旧流程覆盖该聊天并先删除原消息。

原因：归档写入 API 按 ID 替换聊天，而 Operit1 完整导入未事先为冲突 ID 建立迁移映射。

修复：导入前读取现有聊天 ID，为冲突聊天分配新 UUID，并同步重写本批次 parentChatId，保留现有会话。
