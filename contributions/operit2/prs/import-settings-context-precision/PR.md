## 变更说明

原版最大上下文长度使用浮点数，CLI/TUI 与 Flutter 设置编辑器却在初始化输入框时将其格式化为整数。打开一个 `maxContextLength=32.5` 的模型，修改无关开关并保存，也会把原值改写为整数。

两个编辑器都使用保留原数值的字符串表示初始化最大上下文输入，避免用户未编辑该字段时发生有损保存。保存时继续使用现有浮点解析。

本次从增强补丁中只抽取原版现有能力的修复。不新增普通模式上下文字段、自定义摘要规则、编辑器控件或设置项。
