## 变更说明

**问题：** 快照已经写入后，清理或完成引导失败会被当作导入失败；再次继续可能重复提交同一快照或使用已删除的上传。

**原因：** UI 没有记录核心已提交这一不可逆边界，将上传、导入与进入应用放在同一重试分支。

**修复：** 核心返回结果后立即保存完成状态并释放页面对 session 的引用。之后的重试只执行完成引导，按钮和预览明确标注数据已保存，并禁止替换已提交快照。
