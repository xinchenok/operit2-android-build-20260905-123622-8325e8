## 变更说明

### 问题

可见命名会话或隐藏执行器的 shell 已退出时，再次按同一个名称请求会话仍返回旧 sessionId，后续命令无法在有效 shell 中执行。

### 复现步骤

1. 创建一个命名会话或隐藏执行器并让其 shell 退出。
2. 不显式调用 close，再次以相同名称或 executorKey 请求会话。
3. 原实现仅检查 map 内是否有对象，因此仍返回已退出会话。

以上是根据现有控制流整理的复现路径，本次未在 Android 设备上执行。

### 原因

会话映射的存在不代表对应子进程存活；可见和隐藏复用路径都没有轮询退出状态。

### 修复

复用前轮询并缓存进程退出码，只复用仍存活的 PTY；清除失效会话及两个名称映射后按原路径创建新会话。包含必要的 Drop 保护：轮询已回收的 PID 不再被重复发送信号。
