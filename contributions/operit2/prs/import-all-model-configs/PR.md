## 变更说明

复现步骤：现有 Operit2 已配置供应商和密钥，导入含多个 Operit1 供应商以及 SUMMARY 等功能映射的快照。旧流程仅导入 CHAT 所指供应商并覆盖默认供应商。

原因：完整快照复用了单个模型导入函数，固定写入默认 provider ID，且没有遍历其余配置和功能映射。

修复：使用现有供应商备份合并 API 为每个导入配置生成独立 ID 和唯一名称，保留现有配置，转换可用的功能映射并保留原始设置副本；失效非 CHAT 下标报告跳过。
