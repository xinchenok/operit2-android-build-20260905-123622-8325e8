## 变更说明

Flutter 最大上下文长度校验仅检查解析失败和 `<= 0`。`NaN` 或正无穷等可解析的非有限值会绕过此条件，并进入模型设置保存流程。

在现有校验中补充 `isFinite`，使用原有本地化错误提示阻止保存非有限最大上下文长度；继续接受正有限小数。

本次从增强补丁中只抽取原版现有能力的修复。不增加增强版 `contextLength` 的输入或校验，不改变摘要设置。
