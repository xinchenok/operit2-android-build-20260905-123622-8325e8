## 变更说明

复现步骤：全局 CHAT 配置仍有效，但某角色固定绑定的配置已删除或模型下标越界；完整导入该快照。旧代码在构造角色时返回错误，阻断后续聊天和记忆迁移。

原因：角色固定模型解析被当成构造角色的必需条件，与全局默认模型选择的校验相互独立。

修复：保留该角色和固定绑定模式，将无法恢复的模型留空，并在导入结果和日志中说明需重新选择；其余角色和数据继续迁移。
