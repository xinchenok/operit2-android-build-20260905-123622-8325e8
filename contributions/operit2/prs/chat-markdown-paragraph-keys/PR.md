## 变更说明

多个 Markdown 段落间隔使用同一个 ValueKey，在同一父节点下产生重复 key，影响 Flutter 子节点匹配。

原因：段落间隔 key 是全局固定字符串，没有父节点和子节点位置。

修复：用 Markdown 节点 key 与索引区分段落间隔；同步现有尾部间隔测试的查找方式。
