## 变更说明

首次打开空历史聊天时没有创建会话，输入框的首份草稿也无法转移到新会话。

原因：请求 ID 的初始值与首次收到的 null 相等，导致绑定提前返回；绑定逻辑也未启动创建。草稿按 chat ID 缓存，需要从 null 槽位迁移。

修复：允许首次 null 绑定、共享首建 Future，并在首建完成时保留非空草稿。
